출처BleepingComputer · WindowsForum (Der Spiegel·Handelsblatt)

Top Story 3

로그인 없이 4번의 요청 —
Cacti 무패치 제로데이와
오염된 유틸리티 업데이트

4HTTP2SHELL/4HTTP2ROOT · Cacti Core 1.2.31 / 안랩, SoftwareOK 공식 다운로드 경로 Python RAT 확인
  • 보안 연구원 ek0ms savi0r가 오픈소스 네트워크 모니터링 도구 Cacti Core 1.2.31(게스트 계정 활성화 시)의 무패치 제로데이 PoC를 공개했다(The Hacker News) — 인증 없이 4단계 HTTP 요청만으로 2차 SQL 인젝션을 거쳐 서버 명령 실행(popen)에 도달한다
  • 공격 구조: auth_profile.php의 preview_graphs_per_page 정수 검증 누락을 악용해 2차 SQL 인젝션 문자열을 저장 → graph_view.php 호출 시 PHP PDO 다중 쿼리(LIMIT 절)로 poller 테이블 명령을 변조 → graph_realtime.php가 이를 popen()으로 실행 — Cacti는 라우터·스위치 자격증명을 대량 보관하므로 즉시 게스트 계정을 비활성화하고 웹 콘솔을 망분리해야 한다
  • 안랩(AhnLab)은 Windows 인기 파일 관리자 Q-Dir과 DesktopOK 공식 웹사이트의 설치 파일 및 자동 업데이트 경로가 침해되어 Python 기반 원격 제어 악성코드(RAT)가 유포되는 공급망 공격을 포착했다(The Hacker News) — 정상 유틸리티의 자동 업데이트 채널조차 신뢰할 수 없는 만큼 애플리케이션 해시 검증과 EDR 행위 기반 차단이 필수다
출처The Hacker News (Cacti PoC / AhnLab)

Cacti 제로데이는 패치 없는 상태의 PoC 공개로, 인터넷 노출 Cacti는 즉시 게스트 계정 비활성화·웹 콘솔 접근 차단이 필요하다. Q-Dir·DesktopOK 변조는 SoftwareOK 공식 사이트 다운로드·업데이트 경로 영향으로, 배포 버전 해시 대조가 권고된다.

Deep Dive 1

토큰 한 개가 소스코드 전체를 넘긴다 —
SAP·Cloud One이 보여준
연방·엔터프라이즈 동시 압박

  • 1Password 직원 GitHub 침해(25일)와 SAP 'Project Granite' 의혹(27일)은 이틀 차이로 같은 진입점을 확인했다 — 경계 방화벽이 아니라 '개발자 신원 인증 토큰'이 현대 공급망 침투의 표준 입구가 됐다 소스코드가 복제·변조되면 그 아래 모든 산출물(빌드·배포 패키지)의 신뢰가 동시에 무너진다
  • 연방·국방 클라우드 연쇄(FBI NCIC, CIA·ODNI, 재무부 FinCEN, 미 공군 Cloud One)의 공통점도 같다 — 경계가 뚫린 것이 아니라 '자격증명이 훔쳐졌다는' 점이다 클라우드 플랫폼은 '외부에서 접근 불가'라는 전제 자체가 성립하지 않으며, 침해 시 영향 범위가 데이터레이크 단위다
  • 방어 전환점: ① GitHub·클라우드 토큰 수명 단축과 최소 scope 강제 ② 조직 단위 감사 로그·신규 디바이스 승인 활성화 ③ 대량 클론·내보내기(bulk download) 행위 탐지 알람 — 사고 후 토큰 회수가 아니라, 탈취 즉시 무력화되는 짧은 수명 설계가 답이다
출처BleepingComputer · WindowsForum 종합 분석

Cloud One 침해는 보도 단계로 미공식 확인 사항이며, SAP의 고객 데이터 접근 여부도 조사 중이다. '표준 입구' 평가는 1Password·SAP 두 사례의 공통 구조 기반 해석이다.

자율 AI 에이전트가 기반시설을 뚫은 날 —
유럽의 교훈과
국내 연구인력 표적화

  • 스위스는 국가 기반시설이 자율 AI 에이전트 공격에 뚫린 첫 공식 사례다 — ARTEX, CyberStrikeAI, PentAGI는 사람이 하던 정찰·취약점 탐색·침투를 수시간의 폭발적 병렬 요청으로 압축하고, 'DeepSeek Harness(Red Team Mode)'는 내장 프롬프트로 모델 안전 제한을 우회한다 공격 속도가 방어 패치 주기(주 단위)보다 빨라진 것이 본질이다
  • 탐지 열쇠는 페이로드가 아니라 행동 특성이다 — AI 에이전트는 짧은 시간 대량 병렬 요청과 높은 오류율을 남긴다: 버스트 트래픽 상관분석, API 엔드포인트 봇 챌린지, 허니토큰 배치가 3개국 공동 권고의 핵심 여기에 '인터넷 노출 자산 24시간 내 패치'라는 시간 기준을 붙였다
  • 국내 파장은 같은 결의 다른 악장이다 — SEMA 유출(21만 건·16종)은 AI가 개인화 피싱 비용을 0에 가깝게 낮춘 환경에서 연구인력 신상 전체를 공격자에게 넘겼다 탈퇴 회원 미파기와 17시간 탐지 지연이라는 구조적 원인이 그대로 2차 피해(과제·공동연구 사칭 스피어피싱)의 연료가 된다

스위스 공격에 사용된 도구 목록은 당국 발표 기준이며, 국내 연구인력 대상 2차 피해는 발생 전 위험 평가다. 개인정보위 긴급대응 체계 가동은 규제 강화 신호로 해석할 수 있다.
