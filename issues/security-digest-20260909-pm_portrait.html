Top Story 1

Chrome 153 긴급 릴리스
연 7번째 제로데이

CVE-2026-87491 · Active Exploitation
개요
  • Chrome 152 패치 며칠 만에 또 다른 제로데이(CVE-2026-87491) 수정한 Chrome 153 긴급 정식 배포
  • 야생 표적 공격에 실제 악용 중 — 상세 내용은 익스플로잇 진정 후 공개 예정
  • 지난주 V8 타입 혼동(CVE-2026-85046) 패치 직후 새 실행 엔진 결함으로 재공격 감지
  • 2026년 들어 9월 초 기준 7번째 실전 악용 제로데이
출처BleepingComputer — Google warns of new Chrome zero-day / SecurityWeek — Chrome 153 Patches Seventh Zero-Day of 2026

Chrome 153 긴급 릴리스로 CVE-2026-87491 차단. 올해 일곱 번째 실전 악용 제로데이로 브라우저 패치 주기가 공격 속도를 따라가지 못하는 국면.

Deep Dive 1

브라우저 제로데이
인플레이션의 현실

패턴 분석
  • V8·실행 엔진 결함을 연쇄 파고드는 공격 — 패치와 신규 익스플로잇 간 격차(days)가 급감
  • 표적형 피싱 첨부 URL 한 번의 열람이 침투로 직결
권고 조치
  • 긴급 패치 자동화: Chrome 자동 업데이트 강제 + 버전 인벤토리 감시
  • 비신뢰 웹 서핑 트래픽을 격리하는 원격 브라우저 격리(RBI) 도입 검토
  • 임시 완화: 위험 도메인 접근 차단 목록 운영, 확장 프로그램 최소 권한화
출처BleepingComputer / SecurityWeek 분석 종합

연 7회 제로데이는 '패치만으로는 부족'한 임계점. RBI 등 컨테이너 격리가 기업 보안의 핵심 완화책으로 부상.

흐름 해석
