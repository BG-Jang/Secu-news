Top Story 1

Pixel 셀룰러 모뎀
제로클릭 제로데이 패치

CVE-2026-58704 · KEV 등재 · 9.19 기한
개요
  • 구글, Pixel 셀룰러 베이스밴드 모뎀에서 사용자 상호작용 없이 무선 통신 패킷만으로 시스템 권한 탈취하는 제로클릭(Zero-Click) 제로데이(CVE-2026-58704) 공식 확인·패치 배포
  • CISA, KEV에 추가 + 연방 기관에 9월 19일까지 조치 완료 지시 — 제한적 표적 악용 징후 감지, 용병 스파이웨어 연계 추정
출처The Hacker News — Google Patches Pixel Modem Flaw Amid Signs of Limited Targeted Exploitation / SecurityWeek

Pixel 모뎀 펌웨어 인가 로직 결함으로 기지국 신호·조작된 무선 패킷 수신만으로 권한 상승하는 제로클릭 표적 공격. CISA KEV 등재, 9.19 연방 조치 기한.

Deep Dive 1

베이스밴드 레이어의
완전 무인 침투

기술적·장기적 파급
  • OS 샌드박스가 아무리 정교해도 하위 베이스밴드 프로세서가 뚫리면 통화 도청·GPS 위치 추적·기기 원격 제어 가능 — 통신 칩셋 레이어가 모바일 보안의 최심층 사각지대
  • 제로클릭은 링크 클릭 등 사용자 행위 자체가 불필요 — 탐지 자체가 극히 어려워 펌웨어 패치 적용 시점만이 유일한 방어선
권고
  • 정부·기업 주요 인사의 9월 Pixel 펌웨어 업데이트 즉각 적용, MDM으로 패치 수준 전수 검증 + 기지국 모사(Emulation) 공격 감시
출처The Hacker News / SecurityWeek / CISA KEV 고지 종합

베이스밴드 침투는 OS 방어와 무관하게 도청·추적·원격 제어를 허용. 제로클릭은 탐지가 사실상 불가해 펌웨어 패치 시점 적용이 유일한 방어선.

Top Story 2

단일 확장 프로그램으로
AI 비서 탈취 'Hijacking'

Chrome·Edge·Claude 등 5종 기법 공개
개요
  • 보안 연구진(Forever Security), 일반 권한 브라우저 확장 프로그램이 내장 AI 에이전트의 권한 경계를 우회해 최고 권한 내부 API 호출로 기업 기밀·브라우징 컨텍스트 탈취하는 'AI Agent Hijacking' 기법 5종 공개
  • 웹 스토어 유통 단순 테마/번역 확장 프로그램이 내부 메시지 브로커로 AI 비서에 은밀히 프롬프트 주입, 사내 인트라넷 데이터 외부 유출 경로 입증 — Chrome·Edge·Comet·Opera Neon·Claude 대상
출처The Hacker News — One Extension Could Hijack AI Assistants Across Chrome, Comet, Opera Neon, and Claude

단일 확장 프로그램이 브라우저 내장 AI 비서의 권한 경계를 우회해 내부 API를 호출, 기업 기밀과 브라우징 컨텍스트를 탈취하는 신종 취약점 클래스. 테마/번역 확장도 공격 벡터.

Deep Dive 2

브라우저 AI 통합의
보안 설계 허점

기술적·장기적 파급
  • 최신 브라우저가 AI 비서에게 높은 수준의 DOM 접근·탭 제어 권한을 부여하면서, 수년간 격리해 온 확장 프로그램-핵심 프로세스 간 신뢰 경계가 AI 인터페이스로 허물어짐
  • AI 어시스턴트가 확장 요청을 렌더링할 때 상호 인가 절차 부재 — Extension-to-AI 샌드박싱(격리) 표준 미비가 구조적 취약점
권고
  • 내부망 접속 세션에서 확장 프로그램 최소화 + AI 비서의 민감 컨텍스트 접근 제한, 벤더의 Extension-to-AI 상호 인가 표준 도입 여부 추적
출처The Hacker News / Forever Security 연구 종합

AI 비서가 확장 프로그램의 신뢰 경계를 허물었다. Extension-to-AI 샌드박싱 표준이 마련되기 전까지 내부망 세션의 확장 최소화 + AI 컨텍스트 접근 제한이 실질적 완화책.

Top Story 3

CISA·NSA·파이브 아이즈
AD 17대 침해 기법 가이드

Kerberoasting · DCSync · 골든 티켓
개요
  • CISA·NSA 및 파이브 아이즈(Five Eyes) 동맹, 랜섬웨어·APT가 엔터프라이즈 도메인 장악 시 악용하는 Kerberoasting·DCSync·골든 티켓 등 17개 핵심 AD 공격 벡터를 식별한 합동 방어 프레임워크 발표
  • 대규모 랜섬웨어의 90% 이상이 초기 침투 후 Active Directory 설정 오류·레거시 프로토콜을 악용해 도메인 관리자 권한 획득 — 17개 TTPs 심층 해체 + 실시간 이벤트 로그 탐지 쿼리 공개
출처Industrial Cyber — CISA, NSA, global cyber agencies issue guidance to detect and mitigate 17 Active Directory compromise techniques

CISA·NSA·파이브 아이즈가 AD 17대 침해 기법(Kerberoasting·DCSync·골든 티켓 등) 합동 방어 가이드와 실시간 탐지 쿼리를 공개. 랜섬웨어의 도메인 장악 경로에 대한 공동 대응.

Top Story 4

애플 iOS 27·macOS
보안 업데이트 126건

ImageIO 메모리 손상 · 스파이웨어 벡터 차단
개요
  • 애플, iOS 27·macOS 최신 업데이트로 iMessage·웹 렌더링 시 악성 이미지 하나로 기기를 원격 장악하는 ImageIO·CoreGraphics 버퍼 오버플로우 등 스파이웨어 표적 결함 총 126건 일괄 수정
  • NSO 그룹 등 용병 스파이웨어(Mercenary Spyware)가 iMessage 경유로 표적 인사 아이폰을 감염시키는 단골 공격 벡터인 메모리 오염 결함에 ImageIO 파싱 엔진의 메모리 안전성 강화 패치 적용
출처보안뉴스 — 애플, iOS 27 보안 업데이트... 악성 이미지로 아이폰 노리는 취약점 등 126건 대거 수정

애플이 악성 이미지 하나로 기기를 원격 장악하는 ImageIO·CoreGraphics 메모리 손상 등 126건을 일괄 수정. 용병 스파이웨어의 iMessage 제로클릭 벡터 차단에 초점.

Top Story 5

오라클 9월 정기 업데이트
800여 개 패치 배포

WebLogic · Database RCE 다수
개요
  • 오라클, ERP·클라우드 미들웨어 WebLogic Server·엔터프라이즈 데이터베이스 전반에 RCE 가능한 고위험 결함 포함 800개 이상 보안 패치 일괄 발표
  • 외부 접점과 연결되는 WebLogic Server는 제로데이 악용 위험이 높아 우선 패치 대상 지정 — 원격 인증 우회·SQL 인젝션 결함 대거 수정
출처SecurityWeek — Oracle Patches 800+ Vulnerabilities in September 2026 Security Update

오라클이 WebLogic·Database 등 800여 개 패치를 일괄 배포. 외부 노출 WebLogic은 제로데이 악용 위험으로 우선 패치 대상 — 분기 집중 패치 환경의 공백 관리가 관건.

Deep Dive 3

Identity 인프라의
상시 무결성 검증(ITDR)

기술적·장기적 파급
  • 단순 계정 관리를 넘어 Kerberos 티켓 암호화 상향(AES 강제) + 비인가 인증서 템플릿(AD CS) 감사 + Tiered 관리자 권한 분리를 의무화하는 전사적 Identity 위협 탐지·대응(ITDR) 체계 구축 필수
  • 오라클·애플 대규모 패치와 함께 엔터프라이즈 미들웨어 패치 주기 단축 요구 — 시스템 중단 우려로 패치를 미루는 기업이 공격 표적으로 전환
권고
  • AD 17대 TTPs 탐지 쿼리 즉시 적용 + 사전 테스트 자동화·가상 패치(WAF 룰셋)로 패치 공백 최소화, WebLogic 등 외부 접점 우선 대응
출처CISA·NSA AD 가이드 / 오라클·애플 보안 고지 종합 분석

AD 17대 기법 대응과 엔터프라이즈 패치 주기 단축이 맞물린다. ITDR 체계 + AES 강제 + AD CS 감사 + 가상 패치로 Identity 무결성과 패치 공백을 동시에 관리.
