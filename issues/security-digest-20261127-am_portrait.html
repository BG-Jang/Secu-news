Top Story 1

12년 잠복한 커널 급소 —
NFS 서버의 제로클릭 RCE
'NFS2ROOT'

CVE-2026-99362 · nfsd / 무인증 원격 코드 실행 · TCP 2049 점검
  • Linux 커널 내장 네트워크 파일 시스템 서버(nfsd)에서 지난 12년간 발견되지 않았던 제로클릭 원격 코드 실행 결함 'NFS2ROOT'(CVE-2026-99362)가 공개됐다(보안뉴스) — 별도 계정 인증이나 클라이언트 상호작용 없이 네트워크 패킷만으로 커널 권한 코드 실행을 유발할 수 있다
  • 탐지가 어렵다: 공격 트래픽이 정상 NFSv4.1·4.2 프로토콜 규격과 유사해 기존 IDS/IPS 시그니처로 차단하기 힘들다 — 외부에 직접 노출된 NFS 서버뿐 아니라, 내부망에 1차 침투한 뒤 사내 공유 파일 서버와 Kubernetes 영구 볼륨 스토리지 노드를 단번에 장악하는 횡적 이동 핵심 경로로 악용될 우려가 크다
  • 즉시 점검 4항목: 운영 서버 커널 버전, nfsd 모듈 적재 여부, NFSv4.1·4.2 활성 상태, TCP 2049 포트 개방 대역 — 패치 전까지 인가 스토리지 대역 외 2049 차단, /etc/nfs.conf에서 NFSv4.1·4.2 비활성화, 커널 로그의 nfsd4_check_resp_size 경고와 비정상 커널 워커 셸 실행 집중 감시
출처보안뉴스 (NFS2ROOT CVE-2026-99362 경보)

NFS는 사내에서 '내부망이니 안전하다'는 전제로 무인증·무감사 상태로 열리는 대표 프로토콜이다. 커널 내장 모듈 특성상 패치 후 재부팅이 필요하며, 스토리지 노드는 유지보수 창이 길어 실질 노출 기간이 더 길어질 수 있다.

내부망의 무방비 프로토콜 —
NFS2ROOT가 드러낸
스토리지 네트워크의 부채

  • NFS는 '내부망이니까 안전하다'는 전제로 가장 오래 무인증·무감사 상태로 열려 온 프로토콜이다 — NFS2ROOT(CVE-2026-99362)는 바로 그 전제를 정면으로 깨뜨린다: 12년간 커널에 잠복한 결함이 내부망 어느 곳에서든 패킷 한 줄로 커널 권한을 넘긴다 공격자는 경계만 뚫으면(피싱, 약한 VPN, 어제 호의 PAN-OS류 관리 포트) 사내 파일 서버와 Kubernetes 영구 볼륨 노드를 한 번에 쓸 수 있다
  • 탐지·대응이 유난히 어려운 이유 3층 구조: ① 트래픽이 정상 NFSv4.1·4.2 규격과 유사해 시그니처 IDS가 무력 ② nfsd는 커널 내장 모듈이라 애플리케이션 로그가 아니라 커널 로그(nfsd4_check_resp_size 경고, 비정상 커널 워커 셸)를 봐야 잡힌다 ③ 스토리지 노드는 재부팅 유지보수 창이 길어 패치가 확정돼도 실제 적용까지 수 주 노출될 수 있다
  • 방어 원칙: NFS를 '기본 허용 내부 서비스'가 아니라 '명시적 승인 없는 모든 2049는 차단' 대상으로 전환 — ① 인가 스토리지 대역 외 TCP 2049 차단 ② /etc/nfs.conf에서 불필요한 NFSv4.1·4.2 비활성화 ③ 커널 패치 롤아웃 시 스토리지 노드를 최우선 순위에 배치하고 재부팅 창을 사전 확보 — 제로클릭 결함 앞에서 내부망 신뢰는 방어가 아니다

  • NullReceiver의 본질은 'C2 주소'라는 공격 자산을 검열 불가능한 원장 위로 옮긴 것이다 — 서버 압류, 도메인 압류, IP 차단은 모두 중앙 집약점을 전제로 하지만, 이더리움 트랜잭션 한 번이면 7,609개 감염 저장소 전체의 접속처가 동시에 이전한다 대응 창이 '서버 폐쇄'에서 '감염 클라이언트 전수 탐지·차단'으로 옮겨간 셈이며, 개발자 토큰 탈취 → 커밋 재작성이라는 유입 경로 자체가 유일한 차단 지점이 된다
  • 국내 전선은 같은 주제의 다른 악장이다 — 다나와의 선제 전면 중단은 유출 확정 전 '차단 우선' 판단의 사례인 반면, 팸텍 랜섬웨어는 포티넷이 한국 제조업을 최다 표적(24%)으로 지목한 직후 소부장 기업의 현실을 확인시켰다 플랫폼은 회원 데이터, 제조사는 임직원 주민번호·사번과 공정 자료가 맞교환되는 구조다
  • 공통 교훈: '오래된 신뢰'가 곧 부채다 — 12년 묵은 커널 모듈, 서명 없는 커밋 히스토리, MFA 없는 제조 업무망, 해지 후 미파기 백업(어제 호 더존비즈온)이 나란히 오늘의 급소 목록이다 자산 인벤토리에 '방치 기간' 열을 추가하고 1년 이상 무패치·무인증 자산을 우선 해소 대상으로 관리해야 한다
