Top Story 1

Azure AI Foundry
CVSS 10.0 만점 결함 패치

SSRF · 테넌트 경계 침범 · 독점 AI 모델 탈취
개요
  • 마이크로소프트, 기업용 AI 개발 플랫폼 Azure AI Foundry(구 Azure AI Studio)에서 서버 측 요청 위조(SSRF) 및 권한 우회로 타 기업 테넌트 경계를 침범해 독점 AI 모델·파라미터 가중치·미세조정 데이터셋을 탈취할 수 있는 CVSS 10.0 만점 결함 긴급 패치
  • 내부 서비스 간 통신 파서의 검증 부재로 한 테넌트의 비인가 사용자가 내부 토큰을 위조해 타 기업 저장소 접근·기밀 AI 파이프라인 자산 덤프 가능 — 클라우드 PaaS 멀티테넌시의 구조적 결함 사례
출처The Hacker News — Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Enterprise Data Theft

Azure AI Foundry에서 SSRF와 권한 우회를 결합한 CVSS 10.0 결함이 패치됨. 한 테넌트 사용자가 내부 토큰 위조로 타 기업 AI 모델·가중치·학습 데이터셋을 탈취할 수 있었던 구조적 멀티테넌시 결함.

'생각하는황소' 홈페이지 해킹
학생 개인정보 노출 위험

KISA·개인정보위 긴급 조사 착수
개요
  • 국내 대형 수학 교육 플랫폼 '생각하는황소' 웹사이트가 외부 사이버 공격을 받아 백엔드 데이터베이스가 직접 침해 — 수강생·학부모 포털의 웹 취약점을 통한 DB 노출 경로 확인
  • 학생 이름·학교·성적 정보, 학부모 연락처 등 민감 개인정보 유출 가능성 제기 — 피싱 범죄 악용 우려로 KISA와 개인정보보호위원회가 긴급 조사 착수
출처매일경제 — 수학 학원 '생각하는황소' 사이트 해킹…학생 개인정보 유출 가능성 / KISA 보호나라

수학 교육 플랫폼 '생각하는황소' 웹사이트가 해킹당해 학생 이름·학교·성적과 학부모 연락처가 유출됐을 가능성이 제기. KISA와 개인정보보호위원회가 긴급 조사에 착수.

Top Story 3

Gyazo, 2,300만 계정
비공개 이미지 유출

이메일·해시 비밀번호 · Unlisted 스크린샷 인덱스 노출
개요
  • 개발자·기업이 폭넓게 쓰는 스크린샷 캡처·공유 서비스 Gyazo의 DB가 침해돼 2,300만 명의 이메일·계정 정보·해시된 비밀번호 및 비공개 스크린샷 자산 링크가 유출되는 대형 사고
  • '링크를 아는 사람만 본다'는 Unlisted(비공개) 스크린샷 인덱스까지 암시장에 유출 — 소스코드 스니펫·에러 로그·업무 기밀 화면이 대량 노출된 상태
출처SecurityAffairs — Gyazo Data Breach Exposes 23 Million User Records

Gyazo DB 침해로 2,300만 명의 계정 정보와 해시된 비밀번호, 비공개(Unlisted) 스크린샷 인덱스가 암시장에 유출. 사내 기밀 화면이 대량 노출된 상태.

Top Story 4

CISA, 주간 취약점 회보 폐지
'실전 위험 우선순위화' 전환

AI 탐지로 CVE 폭증 · 알림 피로 해소 목적
개요
  • 미 CISA, 수년간 발행해 온 정기 '주간 취약점 회보'를 전격 중단 — AI 도구 도입으로 매월 발견되는 CVE가 기하급수적으로 폭증(9월 MS 966개 패치 등)하면서 단순 나열 방식의 한계 노출
  • 야생에서 실제 악용 중인 KEV 목록과 실시간 위협 인텔리전스 중심의 방어 체계로 단일화 — 보안 담당자의 알림 피로(Alert Fatigue)를 줄이는 정책 전환
파급
  • 모든 취약점 일률적 패치는 더 이상 불가 — CVSS + EPSS(악용 예측 지수) + 야생 공격 지표를 결합한 위험 기반 패치 라이프사이클(RBVM) 운영이 업계 표준으로 부상
출처Cybersecurity Dive — CISA ends weekly vulnerability roundups as part of shift to prioritization

CISA가 주간 취약점 회보 발행을 중단하고 KEV·실시간 위협 인텔리전스 중심의 우선순위 대응 체제로 전환. AI 기반 탐지로 CVE가 폭증하면서 CVSS+EPSS를 결합한 위험 기반 패치 라이프사이클이 표준화되는 흐름.

Top Story 5

신종 뱅킹 트로이목마
'RatHat' 전 세계 확산 경보

접근성 권한 악용 · 2FA 자동 승인 우회
개요
  • 안드로이드 접근성(Accessibility) 권한을 가로채 화면 입력값을 실시간 탈취하고, 은행·암호화폐 앱의 이중인증(2FA) 승인 버튼을 자동 클릭해 계좌 잔액을 은밀히 이체하는 신종 악성코드 'RatHat' 발견
  • 금융 보안 앱·택배 배송 알림으로 위장해 설치 유도, 화면 캡처·가상 키보드 입력·OTP 캡처 수행 — 사람이 눈치채지 못할 속도로 2단계 인증 팝업 자동 수락
파급
  • 루트 권한 없이도 정상 OS 기능을 남용해 보안 장벽 우회가 확산 — 금융 앱 실행 시 비인가 접근성 서비스 감지·차단(Anti-Tamper) 고도화 요구
출처SecurityAffairs — RatHat Turns Android Accessibility Into an Attack Weapon

RatHat은 접근성 서비스 권한을 악용해 화면 입력값·OTP를 탈취하고 2FA 승인 버튼을 자동 클릭하는 신종 뱅킹 트로이목마. 루트 없이 정상 OS 기능을 남용하는 형태라 금융 앱의 비인가 접근성 서비스 차단 정책 고도화가 요구됨.

Deep Dive 1

클라우드 AI 멀티테넌시의
구조적 결함

기술적·장기적 파급
  • AI 모델 가중치와 학습용 사내 문서는 기업 핵심 지적재산권(IP) — 클라우드 벤더의 인프라 레벨 패치만으로 보호가 끝나지 않음
  • 멀티테넌시 환경의 내부 서비스 간 통신 검증 부재는 단일 결함이 테넌트 전체로 전파되는 구조적 리스크 — AI 파이프라인 자산을 일반 데이터와 동일하게 취급하면 안 됨
권고
  • 사내 AI 파이프라인의 프라이빗 엔드포인트(Private Link) 연결 강제 + 고객 관리 키(CMK) 암호화 적용, 테넌트 간 토큰 위조 시나리오에 대한 자체 감사 병행
출처The Hacker News / Microsoft 보안 고지 종합 분석

Azure AI Foundry CVSS 10.0은 멀티테넌시 내부 통신 검증 부재가 독점 AI 모델·가중치·학습 데이터셋 탈취로 직결된 사례. 벤더 패치 외 Private Link 강제와 CMK 암호화, 토큰 위조 시나리오 자체 감사가 필수.

Deep Dive 3

스크린샷 내 민감 정보의
2차 침해 위협

기술적·장기적 파급
  • Gyazo는 개발자·기획자가 소스코드 스니펫·시스템 에러 로그·업무 기밀 화면을 공유하는 용도로 폭넓게 사용 — 계정 유출에 그치지 않고 비공개 이미지 인덱스 자체가 노출됨
  • 이미지 OCR 분석으로 캡처 화면 내 사내 비밀번호·인프라 접근 키(API 키)가 대량 추출될 수 있어 2차 침해 벡터로 전환 — '링크만 모르면 안전'이라는 Unlisted 전제가 무너짐
권고
  • 임직원의 업무용 화면 캡처 클라우드 업로드 통제 + 섀도우 IT 사용 차단, DLP 정책으로 민감 정보 포함 스크린샷 외부 전송 탐지·차단 적용
