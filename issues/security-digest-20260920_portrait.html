Top Story 1

'룩핀', Metabase 취약점 악용
개인정보 유출 공식 공지

미인증 SQL 인젝션 · 이메일·비밀번호 해시 유출
개요
  • 남성 패션 커머스 플랫폼 룩핀(운영사 레벨13), 9월 20일 공지 통해 백엔드 BI 도구 'Metabase'의 보안 취약점 공격으로 회원 이메일·비밀번호 해시 등 유출 공식 확인 — 비상 침해 대응 착수
  • 스타트업·이커머스가 대시보드 시각화로 널리 도입한 Metabase 오픈소스의 미인증 SQL 인젝션 결함을 공격자가 악용, 연동된 회원 DB 테이블 역조회로 계정 정보·비밀번호 해시 탈취

패션 플랫폼 룩핀이 BI 도구 Metabase의 미인증 SQL 인젝션 취약점을 악용당해 회원 이메일·비밀번호 해시가 유출됐다고 공식 공지. 사내 데이터 분석 도구의 인터넷 노출 차단과 최신 패치 유지가 시급한 교훈.

ICS/OT 강제 보안 규제 공표

하드웨어 MFA 의무화 · 인터넷 노출 프로토콜 격리
개요

  • 가이드라인 형태의 '자율적 권고'를 끝내고 16개 핵심 국가 기반시설 운영자에게 의무 적용되는 ICS 보안 명령으로 전환 — 공장 출하 기본 패스워드 방치·인터넷 직결 PLC/SCADA에 연방 감사·제재 수반

Top Story 5

영국 RNLI, 기부자 데이터베이스
해킹 침해 공식 확인

금융 결제·연락처 노출 · ICO 조사 착수
개요
  • 영국 전역 해상 인명 구조를 책임지는 비영리 공공 기구 RNLI(Royal National Lifeboat Institution)의 전산망이 사이버 공격을 받아 후원자 금융 결제 및 개인 연락처 데이터베이스가 노출 — 영국 정보감독원(ICO) 조사 착수
  • 서포터 후원 관리 DB에 비인가 접근 발생, 정기 기부자의 금융 계좌 일부·연락처 정보를 빼돌려 2차 스미싱·사기 범죄를 시도하려는 정황 포착 — 사회적 취약 지대를 노린 사이버 범죄 패턴
출처CyPro — RNLI Cyber Incident: Supporter Data at Risk

영국 해상 인명 구조 비영리 기구 RNLI의 기부자 DB가 해킹돼 금융 결제·연락처 정보가 노출되고 ICO 조사가 시작됨. 기부금으로 운영되는 비영리 기관은 개인정보 보유량 대비 보안 투자가 취약해 손쉬운 타깃.

Deep Dive 1

사내 오픈소스 분석 도구의
인터넷 노출 뇌관

기술적·장기적 파급
  • Metabase·Grafana 등 BI 도구는 전사 고객·비즈니스 데이터와 직결 — 단 하나의 입력 검증 결함(미인증 SQL 인젝션)이 곧바로 전사 개인정보 유출로 직결되는 구조
  • 스타트업·이커머스가 대시보드를 위해 쉽게 인터넷에 노출해 두고 방치하는 패턴이 공격자의 자동 스캐닝에 그대로 포착 — '내부 도구'라는 인식이 오히려 패치·접근 통제 사각지대를 만듦
권고
  • 데이터 분석 도구 포트를 VPN/폐쇄망 내부로 철저히 제한 + 최신 패치 버전 유지, BI·모니터링 도구의 대외 노출 포트 전수 감사와 미인증 엔드포인트 탐지 규칙 적용
출처보안뉴스 종합 분석

룩핀 유출은 사내 BI 도구 Metabase의 인터넷 노출이 전사 개인정보 유출로 직결된 사례. 데이터 분석 도구의 폐쇄망 제한·최신 패치 유지, 미인증 엔드포인트 탐지가 필수 완화책.

Deep Dive 2

권고에서 법적 의무화로
전환되는 OT 보안

기술적·장기적 파급
  • CISA의 ICS 강제 규제는 'Security by Design'을 법적 의무로 전환 — 공장 출하 기본 패스워드 방치, 인터넷 직결 PLC/SCADA 설비에 연방 감사·제재가 수반되는 시대 진입
  • 국가 배후 해킹 그룹의 발전소·수자원 OT 공격이 빈발하면서 운영기술 네트워크의 전면적 제로 트러스트 도입 + 단방향 통신 게이트웨이(Unidirectional Gateway) 구축이 필수로 부상 — 자율 규범에서 강제 컴플라이언스로의 패러다임 전환
권고
  • OT 자산 인벤토리 전수 조사 + 기본 인증정보·인터넷 노출 프로토콜 즉시 격리, IT-OT 경계의 단방향 게이트웨이 도입과 OT 전용 MFA(하드웨어 토큰) 적용 로드맵 수립
출처Security Boulevard 종합 분석

CISA ICS 규제는 OT 보안을 권고에서 법적 의무로 전환하는 분기점. 기본 패스워드·인터넷 노출 PLC/SCADA에 제재가 수반되고, 제로 트러스트+단방향 게이트웨이+하드웨어 MFA가 OT 네트워크의 새 기준선이 됨.

Deep Dive 3

생산 라인 마비 방지를 위한
네트워크 세그멘테이션

기술적·장기적 파급
  • 제조 산업은 공정 중단 1시간당 수억 원의 손실 — 랜섬웨어가 생산 라인 가동을 멈추는 것 자체가 몸값 협상 레버리지가 되는 구조적 취약점
  • SSL-VPN·서드파티 공급망 관리 툴이 자동화 스캐너의 1차 진입점으로 악용 — 사무 IT망과 제조 OT망 간 횡적 이동이 차단되지 않으면 단일 취약점이 생산 전체 마비로 전파
권고
  • 사무 IT망과 제조 OT망 간 완벽한 횡적 이동 차단(세그멘테이션) + 오프라인 에어갭 백업(Air-Gapped Backup) 체계 유지, 원격 관리 툴의 알려진 취약점 패치와 최소 권한 접근 통제 병행
출처Industrial Cyber — Black Kite 2026 보고서 종합 분석

제조업 랜섬웨어 폭증의 핵심은 생산 라인 마비라는 구조적 취약점. IT/OT 세그멘테이션으로 횡적 이동 차단하고, 에어갭 백업으로 복구력을 확보해야 공정 중단 리스크를 방어할 수 있다.
