Top Story 1

F5 BIG-IP APM 제로데이, 미인증
RCE 실전 악용·KEV 등재

CVE-2026-94127 · OAuth 인증 서버 결함 · CISA 9.25 패치 마감 명령
개요
  • F5, 엔터프라이즈 접근 통제 장비 BIG-IP APM이 OAuth 인증 서버로 동작할 때 미인증 원격 공격자가 임의 코드를 실행(RCE)할 수 있는 제로데이 취약점(CVE-2026-94127)을 확인하고 긴급 핫픽스 배포 — CISA가 KEV 목록에 즉시 추가, 연방 기관에 9월 25일까지 패치 완료 명령
  • 인증 토큰 요청 파라미터 파싱 로직 결함으로 사전 로그인 없이 장비 쉘 권한 획득 가능 — 사내 앱에 토큰을 발행하는 OAuth 인가 서버가 장악되면 연동된 모든 SaaS·내부 시스템에 유효한 위조 토큰 발급이 가능한 치명적 구조
출처The Hacker News — F5 Patches Critical BIG-IP APM Zero-Day Exploited for Unauthenticated RCE on OAuth Servers

F5 BIG-IP APM의 OAuth 인증 서버 제로데이가 미인증 RCE로 실전 악용돼 긴급 패치가 배포되고 CISA KEV에 등재. 연방 기관은 9월 25일까지 패치 완료 명령을 받았으며, 전사 F5 게이트웨이 핫픽스 적용이 최우선 과제.

  • 플로리다주 차량국(DAVID) 침해 주장에 이은 후속 표적 — 증거로 요원의 배치 부서와 내부 식별자가 포함된 데이터를 제시, 법 집행 요원에 대한 2차 신변 위협(보복·협박) 우려가 현실화되는 중

Deep Dive 1

전사 인증 허브 장악의
치명성 — OAuth 인가 서버

기술적·장기적 파급
  • F5 BIG-IP APM이 사내 앱에 토큰을 발행하는 OAuth Authorization Server로 동작할 때, 인증 토큰 요청 파라미터 파싱 결함으로 사전 로그인 없이 장비 쉘 권한 획득 — 인가 서버 장악 시 연동된 모든 SaaS·내부 시스템에 유효한 위조 토큰 발급이 가능
  • CISA의 9월 25일 마감 명령은 '인증 인프라 = 최우선 표적'임을 공식화 — F5는 핫픽스 배포와 함께 관련 가상 서버 프로파일 완화 조치를 공지, 전사 게이트웨이 엔지니어링 패치가 시급한 교훈
권고
  • CISA 9.25 마감에 맞춰 전사 F5 BIG-IP APM 핫픽스 최우선 적용 + OAuth 인가 서버 대외 노출 포트 축소·관리망 분리, 토큰 발급 이상 패턴 탐지(단일 클라이언트 과다 발급 등) 규칙 추가
출처The Hacker News 종합 분석

CVE-2026-94127은 OAuth 인가 서버 장악 시 전사 위조 토큰 발급이 가능하다는 경고. CISA 9월 25일 마감에 맞춰 F5 게이트웨이 핫픽스 최우선 적용과 인가 서버 노출 축소, 이상 토큰 발급 탐지가 필수.

Deep Dive 2

법 집행 요원 데이터 유출의
오프라인 안보 위협

기술적·장기적 파급
  • ShinyHunters의 FBI 침해 주장은 엔터프라이즈 인사 관리 시스템(Oracle PeopleSoft) 제로데이를 통한 백엔드 침투 — 배치 부서·내부 식별자 포함 데이터 제시로 신빙성을 확보, 단순 신원 도용을 넘어 보복·협박 등 오프라인 안보 위협으로 번질 수 있는 구조
  • 플로리다 DAVID에 이어 주요 국가 기관 표적이 되면서, 백엔드 ERP·인사 시스템의 인터넷 노출 전면 차단과 내부망 Zero-Trust 검증이 국제적 촉구 사항 — 데이터 갈취 조직의 '정부기관 타깃화' 전략이 고도화되는 중
권고
  • 인사·ERP 시스템의 인터넷 노출 포트 전수 차단 + 내부망 Zero-Trust 접근 검증 도입, 법 집행·정부 기관 요원 대상 2차 신변 위협(스미싱·협박) 대비 개인 경보 체계 가동
출처The Hacker News 종합 분석

FBI 침해 주장은 법 집행 요원 데이터 유출이 오프라인 신변 위협으로 번질 수 있음을 보여준다. 백엔드 ERP·인사 시스템 인터넷 노출 차단, 내부망 Zero-Trust 검증, 요원 개인 경보 체계가 핵심 대응.

Deep Dive 3

다계층 결합 공격과
명절 연휴 회복력 방어

기술적·장기적 파급
  • Chrome V8(1차) + Windows 커널(2차) 연쇄 제로데이는 브라우저-OS 동시 업데이트 강제화의 필요성을 실증 — 애플리케이션 계층과 OS 계층 제로데이가 결합되면 단일 패치만으로는 방어 불능, EDR 메모리 무결성 감시(Exploit Guard) 필수 활성화
  • 명절 연휴는 보안 인력 부재 + 사용자 경계 이완의 이중 취약점 — 생성형 AI로 자연스러운 한국어 피싱이 대량 유포되고, 금융 포털 DDoS 협박이 집중되는 구조. FDS 룰셋 고도화와 24시간 핫라인이 연휴 거래망 회복력의 핵심
권고
  • 브라우저 자동 업데이트 정책 강제 + 엔드포인트 EDR Exploit Guard 활성화 전수 점검, 연휴 기간 이상 금융 거래 탐지(FDS) 룰셋 고도화와 금융사-보안당국 24시간 핫라인 가동 상태 확인
출처The Hacker News · 보안뉴스 종합 분석

Chrome-Windows 연쇄 제로데이는 브라우저-OS 동시 업데이트와 EDR Exploit Guard의 필수성을 보여준다. 명절 연휴는 AI 피싱·DDoS 집중 취약기로, FDS 룰셋 고도화와 24시간 핫라인이 회복력 방어의 핵심.
