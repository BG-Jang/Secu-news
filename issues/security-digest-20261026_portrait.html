Top Story 1

Unit 42 폭로: 유럽 정부 침해 배후는
'자율 에이전틱 AI'

PHP2Shell(CVE-2026-109618/109619) 악용 · 침투 2시간 만에 도메인 관리자 노림
개요
  • 팔로알토 네트웍스 Unit 42, PHP 코어 취약점 PHP2Shell을 악용한 유럽 정부 부처 침해 포렌식 결과 공개 — 침투 성공 후 불과 2시간 만에 인증 DB에서 패스워드 해시·MFA 시크릿 추출, Active Directory NTLM-릴레이 터널로 도메인 관리자 권한 상승 시도
  • 실행된 셸 명령 배치가 ==SHELLUSER==·==PASSWD== 등 LLM 파싱 전용 구분자로 래핑 — 인간이 아닌 자율 에이전틱 AI가 터미널 출력을 기계 파싱해 다음 침투 명령을 스스로 생성·추론한 결정적 시그니처, C2 인프라는 라자루스(Lazarus)의 SyncHole 워터링홀 캠페인과 일치
출처The Hacker News — Unit 42: Agentic AI Conducted Live Intrusion on European Government via PHP2Shell

Unit 42 포렌식으로 LLM 기반 자율 침투 에이전트가 국가 안보망을 실제로 뚫었음이 입증됨. ==SHELLUSER== 등 AI 파싱 전용 구분자와 라자루스 연계 C2가 핵심 IoC. 방어자도 침투 징후 즉시 NTLM 터널 차단·계정 잠금을 수행하는 자율 방어 AI 체계가 필수.

개요
  • 마이크로소프트 위협 인텔리전스·SecurityWeek, 100여 개 LLM을 단일 인터페이스로 호출하는 인기 오픈소스 라이브러리 LiteLLM v1.107.0 공식 릴리스가 오염되었음을 발표 — 메인테이너의 유출된 GitHub CLI OAuth 토큰으로 PR 검토·릴리스 파이프라인을 악의적으로 승인
  • 악성코드는 Python 시동 훅 'sitecustomize.py'로 위장 주입 — 파이썬 런타임 초기화 시 사용자 코드보다 먼저 자동 로드되는 특성 악용, 환경변수를 뒤져 AWS·Azure·GCP 클라우드 자격증명과 OpenAI·Anthropic API 키를 탈취해 공격자 서버로 유출
출처Microsoft Security Blog · SecurityWeek — LiteLLM Supply Chain Attack Steals Credentials via sitecustomize.py Hook

멀티 LLM 게이트웨이 LiteLLM v1.107.0이 공급망 공격 대상이 됨. 라이브러리 해시 고정(Pinning), 격리 컨테이너 내 API 키 주입, sitecustomize.py 등 의심 시동 훅 파일 검사를 의무화해야 한다.

개요
  • CISA·지멘스 ProductCERT, 플랜트 공정 제어·감시 SCADA 표준 SIMATIC WinCC(V7.5/V8.0/V8.1)에서 데이터베이스 역할 권한 검증 미흡으로 원격 비인가 명령 실행이 가능한 CVSS 8.8 고위험 결함 공개 — 산업 에지 앱 퍼블리셔의 Node.js RCE 결함 체인도 함께 공지, 긴급 패치 권고
  • 공장 네트워크 접근 가능한 공격자가 DB 역할 조작으로 SCADA 호스트 기저 OS 최고 권한 획득 → PLC 통신 파라미터·센서 임계치 등 공정 자동화 로직 위변조 가능 — 스마트 팩토리 중앙 공정 감시 서버 장악이 물리 설비 작동 조작으로 직결

WinCC V8.0은 Update 11 이상, V8.1은 Update 7 이상 업그레이드 권고. 패치가 없는 V7.5는 SCADA 호스트 네트워크 분리·데이터베이스 포트 접근 차단이 유일한 완화책.

Deep Dive 1

에이전틱 AI 침투의 킬체인 해부
— ==SHELLUSER== 시그니처

기술적·장기적 파급
  • 초기 침투(PHP2Shell) → 2시간 내 인증 DB 탈취(해시+MFA 시크릿) → NTLM-릴레이 터널로 도메인 관리자 상승의 킬체인을 인간 개입 없이 AI가 완수 — 명령 출력이 ==SHELLUSER==·==PASSWD== 등 정형 섹션 헤더로 래핑된 것은 LLM이 이전 출력을 파싱해 다음 명령을 생성하는 에이전트 루프의 지문
  • C2 인프라가 라자루스의 SyncHole 워터링홀 캠페인·정부·금융 표적 우선순도와 정확히 일치 — 국가 배후 조직이 AI 에이전트화를 선점했음을 시사, 정찰-횡적이동 속도가 인간 SOC 대응 임계치를 초과
권고
  • 셸·원격 명령 로그 내 ==SHELLUSER==류 AI 파싱 구분자 탐지 룰 추가 + NTLM 릴레이 이상 트래픽(다중 계정 단일 소스 인증) 실시간 차단·자동 계정 잠금 플레이북, PHP 인프라 즉시 패치·가상 패치 적용
출처The Hacker News · Unit 42 종합 분석

AI 파싱 전용 구분자와 NTLM 릴레이 터널이 에이전틱 공격의 결정적 IoC. 침투 징후 즉시 터널 차단·계정 잠금을 수행하는 자율 방어 AI와 AI 시그니처 탐지 룰이 신규 필수 통제.

Deep Dive 2

AI 개발 생태계 공급망 방어
— 시동 훅·토큰 유출 대응

기술적·장기적 파급
  • 공급망 공격의 새 경로 — 패키지 코드 자체가 아니라 릴리스 신뢰 체계(GitHub CLI OAuth 토큰 유출→PR/릴리스 승인 우회)가 뚫렸다 — 인기 라이브러리의 공식 릴리스라는 '정품 신뢰' 전제가 무너짐
  • sitecustomize.py는 어떤 import보다 먼저 실행되는 Python 시동 훅 — 탐지 어려운 상시 자격증명 스틸러로 악용, AI 파이프라인의 클라우드 자격증명·LLM API 키가 한 번에 대량 유출되는 단일 장애점 형성
권고
  • LiteLLM v1.107.0 사용 즉시 격리·버전 변경, sitecustomize.py/usercustomize.py/.pth 파일 전수 검사 + 환경변수 기반 시크릿 운용 중단(시크릿 매니저·격리 컨테이너 주입으로 전환), requirements 해시 고정(Pinning)과 CI 내 서드파티 래퍼 설치 통제, 노출된 클라우드 키·API 토큰 전면 재발급
출처Microsoft Security Blog · SecurityWeek 종합 분석

릴리스 신뢰 체계 자체가 공격면이 된 사례. v1.107.0 격리, 시동 훅 파일 검사, 환경변수 시크릿 금지, 해시 고정, 노출 키 전면 재발급이 즉각 조치.

Deep Dive 3

OT 코어 위협과 '블랙 옥토버'
— 패러다임 전환의 두 축

기술적·정책적 파급
  • WinCC CVE-2026-59241은 IT 권한 상승이 물리 설비 조작으로 직결되는 OT 코어 결함 — V7.5 미패치 유지 시 네트워크 분리가 유일한 완화책, Node.js RCE 체인과 결합해 엣지-코어 경계 전체가 침투 경로
  • '블랙 옥토버'는 개별 사고가 아니라 AI로 공격 주기가 분 단위로 압축된 구조적 전환점 — 이번 주의 에이전틱 AI 실전 침투(Unit 42)·공급망 오염(LiteLLM)·OT 코어 결함(WinCC)이 모두 패치 의존 방어 모델의 한계를 가리킴, 국가 인프라는 Assume Breach+ZTA+자율 AI 관제로의 전환 요구
권고
  • WinCC V8.0→Update 11 / V8.1→Update 7 업그레이드, V7.5 호스트는 DB 포트 접근 차단·망 분리 + AI 공격 가속 전제 하에 취약점 관리 SLA 재설계(제로데이 노출→가상 패치 시간 목표), 제로 트러스트 접점 확대 로드맵 단축
출처Security Boulevard · The Guardian 종합 분석

OT 코어 결함(WinCC)과 AI 사이버전 구조화(블랙 옥토버)라는 두 축이 이번 주를 관통. 패치 업그레이드+망 분리 등 기본기와 Assume Breach·ZTA·AI 관제 전환을 병행해야 한다.
