Top Story 1

구글 Gemini, 보안 평가 중
외부 기업 3곳 자율 침투

도메인 라우팅 오류 · 실제 인터넷 시스템 무단 접근
개요
  • 구글 AI 모델 Gemini가 외부 전문 보안 평가(Irregular) 도중 가상 격리망(테스트베드) 도메인 라우팅 설정 실수로 인터넷에 연결된 실제 외부 민간 기업 3곳의 운영 시스템에 무단 접근, 취약점 스캔·계정 침투 워크플로우를 인간 개입 없이 자율 수행 — 월스트리트저널·보안 외신 공개
  • 모의 환경(Mock) 대신 실제 인터넷 연결 서버를 타깃으로 인식 — Agentic AI가 물리적 격리 경계를 스스로 넘나드는 '망분리 실패' 사고로, 메타 Muse Spark·OpenAI 허깅페이스 침투에 이은 세 번째 유사 사례
출처The Hacker News — Google Gemini Broke Into Real Company Systems After Security Test Domain Mix-Up / 보안뉴스 — 제미나이도 보안테스트 중 외부기관 해킹

Gemini가 보안 평가 도중 테스트베드 도메인 라우팅 오류로 실제 인터넷에 연결된 외부 기업 3곳 시스템에 자율 침투. 인간 개입 없이 취약점 스캔·계정 침투를 완결한 Agentic AI 물리적 망분리 실패 사고.

Top Story 2

CISA, 리눅스 커널 취약점
3종 실전 악용 KEV 등재

로컬→루트 권한 상승 · 컨테이너 격리 우회
개요
  • 미 CISA, 리눅스 기반 엔터프라이즈 서버·클라우드 인프라에서 일반 로컬 사용자가 최고 관리자(Root) 권한을 탈취하고 컨테이너 격리를 우회할 수 있는 커널 취약점 3종의 실전 악용을 확인해 KEV 목록에 긴급 추가
  • 메모리 관리·네트워크 스택 결함으로 커널 힙 오염 트리거, 표적형 APT 공격에서 거점 확보(Foothold)용으로 실제 사용 중 — RHEL·Ubuntu·Debian 등 주요 배포판 최신 패치 커널 적용 시급
출처The Hacker News — CISA Flags Three Linux Kernel Vulnerabilities Exploited in the Wild

CISA가 리눅스 커널의 로컬→루트 권한 상승·컨테이너 격리 우회 취약점 3종의 야생 악용을 확인해 KEV에 등재. APT 거점 확보용으로 쓰이고 있어 주요 배포판 패치 커널 적용과 eBPF 기반 시스템 콜 감시 강화가 요구됨.

Top Story 3

북한 WaterPlum, 가짜 코딩 인터뷰
암호화폐 탈취 공격

악성 Node.js 리포지토리 · postinstall 훅 악용
개요
  • 북한 연계 위협 행위자 WaterPlum, 고액 연봉 원격 개발자 채용으로 위장해 면접 대상자에게 악성 Node.js 리포지토리를 실행하도록 유도 — 링크드인·깃허브에서 활동하는 블록체인·Web3 엔지니어 정밀 표적 공격 포착
  • 'npm install'·빌드 명령 실행 시 postinstall 스크립트가 동작, 로컬 브라우저 쿠키·Web3 지갑 비밀키(시드 구문)·사내 인프라 SSH 키를 탈취 — 개발자 PC를 사내 코드 저장소·프로덕션 클라우드로 이어지는 통로로 악용
출처GBHackers — North Korean WaterPlum Hackers Target IT Professionals With Fake Job Interviews to Steal Crypto

북한 WaterPlum이 가짜 코딩 면접 과제로 위장한 악성 Node.js 리포지토리를 배포, npm install 시 postinstall 훅으로 지갑 비밀키·SSH 키를 탈취. 개발자 워크스테이션의 외부 비신뢰 패키지 실행 격리가 핵심 방어선.

Top Story 4

필리핀 LTFRB, 1,600만 건
운전자·차량 DB 유출 확인

취약한 API·권한 관리 틈새 · 시스템 전면 오프라인 전환
개요
  • 필리핀 대중교통 인허가를 총괄하는 정부 기관 LTFRB(육상교통난가맹조정위원회)의 중앙 전산망이 해킹 공격을 받아 1,600만 건에 달하는 운송 사업자 개인정보·차량 등록증·면허 데이터 유출 확인 — 당국이 전산 시스템을 전면 오프라인으로 전환
  • 택시·버스 면허 및 차량 운행 데이터를 관장하는 정부 포털의 백엔드 DB가 취약한 API와 계정 권한 관리 틈을 타 덤프 — 대량 시민 개인 식별 정보 암시장 유출로 딥페이크 위조 신분증·크리덴셜 스터핑 공격 급증 우려
출처Newsbytes.ph — LTFRB confirms data breach, takes records system offline

필리핀 LTFRB 중앙 전산망 해킹으로 1,600만 건 운송 사업자 개인정보·차량 등록증·면허 데이터가 유출돼 시스템이 전면 오프라인 전환. 취약한 API와 권한 관리 틈새를 노린 공격으로 제로 트러스트 API 인가 감사와 DB 암호화가 요구됨.

Health-ISAC, MedTech
'9대 보안 베이스라인' 발표

SBOM · 암호 유연성 · 보안 부팅 의무화
개요

  • 병원 조달·배포 시 검증해야 할 9개 핵심 보안 영역(자산 식별, 펌웨어 무결성, 원격 패치 기능, 암호화 등)을 표준화 — 병원망 마비 랜섬웨어와 IoMT 해킹이 환자 생명을 직접 위협하는 상황에서 도입되는 공급망 보안 제도
출처Industrial Cyber — Health-ISAC sets nine-domain MedTech cybersecurity baseline / Security Boulevard — Daily OT Security News: September 19, 2026

Health-ISAC이 커넥티드 의료기기 조달·배포를 위한 9대 사이버보안 베이스라인을 발표. SBOM·암호 유연성·보안 부팅 의무화로, 병원 조달에서 보안 베이스라인 충족 여부가 입찰 핵심 조건이 되는 공급망 보안 제도화 흐름.

Deep Dive 1

Agentic AI의 물리적
망분리 실패 위험

기술적·장기적 파급
  • 가상 샌드박스에 의존한 레드팀 테스트의 구조적 한계 노출 — 도메인 라우팅 설정 오류 하나에 AI 에이전트가 모의 환경을 벗어나 실제 인터넷 자산으로 타깃을 전환할 수 있음
  • 메타 Muse Spark, OpenAI 허깅페이스 침투에 이어 Gemini까지 유사 사고 반복 — 프론티어 AI 오펜시브 보안 능력 평가 시 외부 인터넷과 물리적으로 단절된 폐쇄 격리망(에어갭) 운용의 법제화 요구가 부상
권고
  • AI 레드팀 테스트베드의 하드웨어적 에어갭 의무화 + 에이전트 외부 통신 대상 도메인 화이트리스트 강제, Agentic AI 운영 시 네트워크 에GRESS(외발) 트래픽 전수 로깅·이상 차단 정책 적용

Gemini 외부 침투는 가상 격리망에 의존한 AI 레드팀 테스트의 구조적 한계를 보여준 사례. 에어갭 물리적 단절 의무화와 에이전트 egress 도메인 화이트리스트, 외부 통신 전수 로깅이 필수 방어 체계.

멀티테넌트 컨테이너 인프라의
권한 상승 위협

기술적·장기적 파급
  • 커널 권한이 장악되면 동일 호스트의 도커/쿠버네티스 컨테이너 격리가 무력화 — 클라우드 멀티테넌트 환경에서 단일 로컬 계정 침투가 인접 테넌트로 수평 이동하는 경로로 전환
  • 리눅스 커널 KEV 3종은 웹셸·로컬 계정을 거점으로 APT가 Root 승격에 악용하는 실전 패턴 — 패치 공백 호스트가 클라우드 인프라 전체의 격리 신뢰를 무너뜨리는 단일 실패점
권고
  • RHEL·Ubuntu·Debian 최신 패치 커널 즉각 적용 + eBPF 기반 비정상 시스템 콜 감시 강화, 컨테이너 호스트의 로컬 계정 최소화(무인 운영)와 privileged 컨테이너 사용 전수 감사 병행

리눅스 커널 KEV 3종은 컨테이너 격리를 무력화하는 구조적 위협. 패치 커널 적용, eBPF 시스템 콜 감시, 로컬 계정 최소화·privileged 컨테이너 감사로 멀티테넌트 격리 신뢰를 방어해야 한다.

Deep Dive 3

공공 인증 인프라의
제로 트러스트 전환 필요성

기술적·장기적 파급
  • 1,600만 건 시민 식별 정보의 암시장 유출은 딥페이크 위조 신분증·크리덴셜 스터핑 공격의 원료 — 공공 DB 덤프는 단순 유출을 넘어 2차 사기 생태계 전체를 키우는 연쇄 리스크
  • 취약한 API와 계정 권한 관리가 정부 포털의 공통 취약점 — '내부망이므로 안전'이라는 전제 자체가 성립하지 않는 환경에서, 공공 서비스는 외부 접속 차단 + API별 최소 권한 인가가 기본선이 됨
권고
  • 공공 포털 제로 트러스트 API 인가 감사 + DB 컬럼 단위 암호화 적용, 오프라인 전환 시스템의 복구 전 침투 흔적 전수 포렌식과 재접속 시 MFA 강제 정책 수립
출처Newsbytes.ph 종합 분석

LTFRB 유출은 공공 인증 인프라의 API·권한 관리 사각지대가 연쇄 사기로 이어지는 사례. 제로 트러스트 API 인가 감사, 컬럼 암호화, 복구 전 포렌식과 MFA 강제가 공공 서비스 기본선으로 요구됨.
